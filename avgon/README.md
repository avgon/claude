# AVGON — İçerik Stratejisi & Üretim Sistemi

Bu klasör @avgon (Metin Kılagöz) Instagram hesabı için içerik stratejisi, üretim sistemi ve haftalık planlama dosyalarını tutar.

## Dosyalar

| Dosya | Amaç |
|-------|------|
| `AVGON_SYSTEM.md` | Marka brief'i, ton, ton kuralları, format şablonları, ölçüm rubric'i. Tek doğruluk kaynağı. |
| `HOOK_BANK.md` | 50 hazır hook (10 formül × 5 hook). Doğrudan kullanıma hazır. |
| `FIRST_10_IDEAS.md` | İlk 10 içerik fikri, her biri 14 alan framework'ünde tamamlanmış. |
| `CONTENT_CALENDAR_30DAYS.md` | 30 günlük yayın takvimi — sütun, tier, seri dengeli. |

## Kullanım

İçerik üretirken sırasıyla:
1. `AVGON_SYSTEM.md` §12 (Output Framework) açılır
2. `HOOK_BANK.md`'den 3 farklı formülde hook seçilir
3. `CONTENT_CALENDAR_30DAYS.md`'e göre tarih + tier + sütun belirlenir
4. Üretim → yayın → 48 saat sonra ölçüm rubric'i (AVGON_SYSTEM.md §14)

## İterasyon

Her ay sonunda:
- En iyi performans gösteren formatlar → Bet/Flagship'e terfi
- Düşük hook rate'liler → format değiştir, yeniden test
- Yeni hook formülleri keşfedilirse HOOK_BANK.md'ye eklenir
